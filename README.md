# Nocturne

Личный музыкальный плеер для SoundCloud без рекламы: ваши плейлисты и лайки, рекомендации, фоновое воспроизведение на iPhone. Это PWA: ставится на iPhone без App Store и без Mac.

**Приложение:** https://madecursed.github.io/freeplay/

## Установка на iPhone
1. Откройте адрес в **Safari**.
2. Нажмите «Поделиться» → «На экран Домой».
3. Запускайте с иконки. Обновления подтягиваются сами.

Не удаляйте иконку: вместе с ней iPhone удаляет библиотеку и настройки приложения.

## Как это работает
- **Воспроизведение.** Треки играют через официальный встраиваемый плеер SoundCloud. Ключ API не нужен.
- **Импорт.** Ссылки на треки, плейлисты и профили, можно несколько сразу. Подключение своего профиля по нику. Плейлисты сами синхронизируются при запуске.
- **Рекомендации как в SoundCloud.** На главной только ваша музыка и новинки ваших исполнителей. Когда очередь заканчивается, автоплей включает станцию по последнему треку: похожие исполнители (Deezer), другие треки исполнителя, его лайки. Подробно: [docs/RECOMMENDATIONS.md](docs/RECOMMENDATIONS.md).
- **Данные** хранятся только на телефоне (localStorage).

## Разработка
```bash
npm install
npm run dev       # локально; с телефона — по адресу Network в той же Wi-Fi сети
npm run build     # проверка типов + сборка
npm run deploy    # сборка и публикация на GitHub Pages (ветка gh-pages)
```
В PowerShell, если скрипты запрещены, используйте `npm.cmd`.

## Структура
```
src/
  main.tsx, update.ts     запуск, автообновление
  types.ts                Track, Playlist
  player/                 воспроизведение: очередь, автомикс, два скрытых плеера SoundCloud
  recommend/              профиль вкуса, оценка, подборки; deezer/ — похожие исполнители
  sync/                   импорт ссылок и профиля, автосинхронизация
  storage/                библиотека, история, настройки (на телефоне)
  ui/                     экраны (screens/), компоненты (components/), навигация, темы
public/                   PWA: manifest, service worker, иконки, фото (art/)
scripts/                  deploy.mjs, duotone.ps1 (обработка фото)
docs/                     алгоритм подбора, источники фото
worker/                   прокси SoundCloud API — понадобится только с подпиской Artist Pro
```

## Ограничения
- Без ключа API SoundCloud нет поиска по всему каталогу, станций и «похожих треков». Видны только последние ~20 лайков пользователя.
- iPhone разрешает звук только в ответ на нажатие, поэтому иногда трек нужно запустить кнопкой ▶.
- Фото в интерфейсе взяты с Wikimedia Commons под свободными лицензиями: [docs/ART_CREDITS.md](docs/ART_CREDITS.md).
