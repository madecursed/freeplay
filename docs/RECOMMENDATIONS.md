# Подбор музыки в Nocturne

Принцип «как в SoundCloud»:
- **Главная показывает только вашу музыку**: плейлисты, избранное, недавно прослушанное, а также новые треки исполнителей, которых вы слушаете. Сгенерированных подборок нет.
- **Похожую музыку подбирает автоплей.** Когда очередь заканчивается, включается станция по последнему треку, как в SoundCloud.

Nocturne работает без ключа API SoundCloud. Станции и «похожие треки» самого SoundCloud недоступны: проверено, встраиваемый плеер их не отдаёт. Поэтому станция собирается из того, что доступно, плюс похожие исполнители из Deezer.

## Где это в коде

| Файл | Что делает |

| [src/recommend/autoplay.ts](../src/recommend/autoplay.ts) | **Станция по треку** — автоплей |
| [src/recommend/deezer/](../src/recommend/deezer/) | Похожие исполнители по данным Deezer, поиск их на SoundCloud |
| [src/recommend/discovery.ts](../src/recommend/discovery.ts) | Треки и лайки исполнителей (кэш), «Новое от твоих артистов» |

## 1. Автоплей: станция по треку

Срабатывает, когда в очереди остаётся 3 трека или меньше и включён «Автомикс» (по умолчанию включён, переключатель в меню ⋯ плеера). Добавляет 15 треков, похожих на **текущий** трек:

```
текущий трек (исполнитель X)
 ├─ ~50%  похожие на X по Deezer ──► их популярные песни (по 6 от каждого, до 4 исполнителей)
 ├─ ~25%  другие песни X ──────────► 12 самых популярных, в случайном порядке
 └─ ~25%  что X лайкает в SoundCloud ► в случайном порядке, кроме его собственных
порядок: похожий, похожий, свой, лайк, похожий, похожий, …
```

Правила станции:
- не больше 2 треков одного исполнителя, для самого X — 3;
- похожие исполнители идут по очереди, а не пачкой;
- пропускаются 50 последних прослушанных треков, треки уже в очереди, «Не рекомендовать» и скрытые исполнители;
- пропускаются «не песни»: подкасты, радиошоу, интервью, записи короче 1 минуты и длиннее 10 минут.

**Запасной вариант.** Если у трека нет ID исполнителя или станция набрала меньше 5 треков, добор идёт из библиотеки по профилю вкуса (раздел 4).

Кнопка **«Твоя ночная волна»** на главной запускает последний прослушанный трек, а дальше автоплей сам продолжает станцией. Трек запускается прямо по нажатию, иначе iPhone не даст включить звук.

## 2. Похожие исполнители: Deezer

Отдельный модуль [src/recommend/deezer/](../src/recommend/deezer/). Deezer знает, какие исполнители похожи: эти связи построены по прослушиваниям миллионов людей. Музыка при этом играет из SoundCloud.

| Файл | Что делает |
|---|---|
| `api.ts` | Клиент публичного API Deezer, без ключа. Работает через JSONP: Deezer не отдаёт CORS-заголовок |
| `match.ts` | Ищет исполнителя Deezer на SoundCloud |
| `similar.ts` | Связывает шаги: исполнитель → похожие по Deezer → профили SoundCloud. Кэш на 3 дня |

Как исполнитель находится:
1. **Поиск в Deezer.** Берётся только точное совпадение имени с наибольшим числом фанатов, потому что первым в выдаче бывает тёзка.
2. **Похожие.** Запрос `/artist/{id}/related` возвращает 14 исполнителей.
3. **Поиск на SoundCloud.** Сначала в вашей библиотеке. Если там нет, угадываем ник для `soundcloud.com/<ник>`: имя слитно, через дефис, через подчёркивание, `+official`, `+music`. Кириллица транслитерируется: «Три дня дождя» → `tri-dnya-dozhdya`.
4. **Проверка.** Каждый вариант проверяется через официальный oEmbed, и **имя профиля сверяется** с именем исполнителя. Так отсекаются чужие аккаунты.
5. **Кэш.** Найденные хранятся 14 дней, ненайденные — 3 дня.

В проверке нашлись 28 из 30 похожих исполнителей, включая русскоязычных. Выключить: «Профиль → Похожие исполнители в автоплее». Тогда станция состоит из треков и лайков самого исполнителя.

## 3. «Новое от твоих артистов»

Для 5 исполнителей, которых вы реально слушаете, загружаются их треки. На главной показываются самые свежие по дате публикации. Учитываются только треки, которых нет в вашей библиотеке, не больше 3 от одного исполнителя.

Вес исполнителя складывается так:

| Сигнал | Вклад |
|---|---|
| Каждый его трек в избранном | +2 |
| Каждое прослушивание среди последних 120 | +1 |
| Каждый трек в импортированных плейлистах | +0.3 |
| Вес `artist:` в профиле вкуса | ×3 |

Из 12 лучших случайно, пропорционально весу, берутся 5, поэтому новинки разных исполнителей чередуются. Скрытые исполнители и те, кого вы часто пропускаете (вес в профиле ниже −1), исключаются. Данные кэшируются на 12 часов. Кнопка ↻ обновляет вручную.

## 4. Профиль вкуса

Используется для миксов по настроению и для запасного варианта автоплея. Каждый трек описывается признаками: `artist:<исполнитель>`, `genre:<жанр>` и до 6 тегов `tag:<тег>`. Ваши действия меняют их вес:

| Действие | Сигнал |
|---|---|
| Дослушал до конца | +1 |
| Лайк | +3 |
| Снял лайк | −3 |
| Пропустил в первые 30 секунд | −1 |
| «Не рекомендовать трек» | −4 |

Вес признака вдвое уменьшается каждые 30 дней. Оценка трека считается так:

```
оценка = (сумма весов признаков) / √(число признаков)  +  случайное 0…1.2  −  3, если играл среди последних 30
```

**Настроение** (экран ✦): берутся треки из библиотеки и кэша исполнителей, у которых жанр или теги совпадают с тегами настроения из `moods.ts`, и сортируются по оценке.

## 5. Ограничения без API SoundCloud

- Встраиваемый плеер отдаёт только **последние ~20 лайков** и первую страницу треков пользователя. Поэтому станции короче и проще, чем в самом SoundCloud.
- Профиль исполнителя по нику находится не всегда. Иногда находится фан-аккаунт с тем же именем.
- iPhone разрешает звук только в ответ на нажатие. Как это обходится — см. комментарии в [src/player/scWidget.ts](../src/player/scWidget.ts): два плеера, предзагрузка, «разогрев».
- С подпиской Artist Pro можно получить ключ API (прокси готов в `worker/`) и подключить настоящие станции и «похожие треки» SoundCloud.

## 6. Как настраивать

| Константа | Файл | Что меняет |
|---|---|---|
| `limit` (15), пропорции `pools` | autoplay.ts | длина и состав станции |
| `sims.slice(0, 4)`, `slice(0, 6)` | autoplay.ts | сколько похожих исполнителей и их треков |
| `SEEDS`, `CACHE_TTL`, `PER_LIST` | discovery.ts | новинки: сколько исполнителей, как часто обновлять |
| `TTL` | deezer/similar.ts, deezer/match.ts | как часто заново спрашивать Deezer |
| `SIGNAL`, `HALF_LIFE_DAYS` | profile.ts | реакция на лайки и пропуски, скорость забывания |
| `MOODS` | moods.ts | настроения и их теги |
